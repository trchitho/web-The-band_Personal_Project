# 🎵 WebTheBand

Đây là dự án thực hành dựa trên **Band Template** từ [W3Schools](https://www.w3schools.com/w3css/tryw3css_templates_band.htm).

## 📂 Cấu trúc thư mục

```

WebTheBand/
│
├── assets/
│   ├── css/
│   │   └── style.css
│   └── font/
│       └── themify-icons/
│           ├── demo-files/
│           ├── fonts/
│           ├── ie7/
│           ├── SVG/
│           ├── index.html
│           ├── readme.txt
│           ├── Themify IconFont.html
│           └── themify-icons.css
│
├── img/              # hình ảnh
├── Components/       # các thành phần giao diện
├── index.html        # trang chính

```

## 🚀 Tính năng

- Giao diện web ban nhạc đơn giản, responsive.
- Sử dụng framework **W3.CSS**.
- Style tuỳ chỉnh trong `assets/css/style.css`.
- Sử dụng **Themify icons** cho giao diện.

## 🛠️ Cách chạy

1. Clone repository về máy:
   ```bash
   git clone https://github.com/<tên-người-dùng>/WebTheBand.git
   ```

```

2. Mở file `index.html` bằng trình duyệt.
```
